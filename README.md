# B站会员画质下载器

这是一个面向 Windows 和 Microsoft Edge 的桌面工具。程序读取本机 Edge 中的 B 站登录状态，获取当前账号真正可用的画质，然后下载视频、音频并合并为 MP4。

作者：蘑菇

## 快速使用

1. 首次使用先双击 `安装Edge扩展.bat`。
2. 在打开的商店页面安装 `Get cookies.txt LOCALLY`；如果 Edge 询问，请允许安装其他商店的扩展。
3. 在 Edge 中登录 B 站大会员账号，打开 B 站页面并通过扩展导出当前站点的 Netscape `cookies.txt`。
4. 双击 `启动下载器.bat`，点击“读取导出文件”并选择刚才生成的文件。
5. 输入或粘贴视频网址；也可以先在 Edge 打开视频，再回到程序点击“读取 Edge 当前页”。
6. 点击“获取可用画质”，选择画质和保存目录，然后开始下载。

程序不需要安装 Python。下载组件保存在 `tools` 文件夹，配置保存在 `config.json`。

## 为什么改用 Edge 扩展

新版 Edge 的 Cookie 数据库存在文件占用和应用绑定加密。直接读取时，浏览器打开可能提示数据库占用，完全退出后又可能无法解密。因此程序不再直接读取 Edge Cookie 数据库。

请只安装名称完整包含 `LOCALLY` 的 `Get cookies.txt LOCALLY`，不要安装名称相近的旧扩展。导出时只在 B 站页面操作，并选择当前站点 Cookie。Cookie 文件等同于登录凭据，不要发送给其他人。

## 已实现功能

- 输入 B 站或 `b23.tv` 视频网址；
- 从已打开的 Edge 当前页面读取网址；
- 使用 Edge 扩展导出的大会员登录状态读取会员画质；
- 动态显示分辨率、帧率、编码、HDR 和预估大小；
- 选择实际视频格式并自动匹配最佳音轨；
- 自动使用 FFmpeg 合并并输出 MP4；
- 指定保存目录、显示实时进度、保留运行日志；
- 一键打开下载文件路径；
- 可配置默认画质，初始默认优先选择 1080p 60fps；
- 可配置默认视频编码，支持自动、AVC、HEVC、AV1，初始默认 AVC；
- BAT 启动后自动关闭命令窗口，下载器独立运行；
- 支持取消，失败时保留未完成文件以便续传；
- 记忆保存目录、Cookie 模式和 Cookie 文件路径。

## 注意事项

- 默认只下载网址对应的单个视频或当前分 P，不自动下载整个合集。
- 大会员账号并不保证每个视频都有 4K、HDR、杜比视界等画质，列表以视频和账号实际返回的结果为准。
- 仅下载你拥有合法访问权、且相关规则允许保存的内容。
- B 站接口可能调整；出现解析问题时，可删除 `tools\yt-dlp.exe` 后重启，让程序重新下载兼容版本。

## 文件说明

- `启动下载器.bat`：推荐的双击入口，启动失败时会保留错误信息。
- `安装Edge扩展.bat`：打开 `Get cookies.txt LOCALLY` 的扩展商店页面。
- `start.cmd`：备用控制台入口。
- `bootstrap.ps1`：下载或更新运行组件，然后启动界面。
- `app.ps1`：图形界面和下载逻辑。
- `tools`：首次运行后生成，保存 `yt-dlp.exe` 和 `ffmpeg.exe`。
- `runtime`：下载时生成临时日志；成功后自动清理对应日志。
